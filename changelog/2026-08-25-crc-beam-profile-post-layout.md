# CRC beam profiles and live post layout

- The selected Beam panel now separates solid 4× profiles from 2025 CRC built-up profiles: (2) and (3) ply 2×6, 2×8, 2×10, and 2×12 PT.
- Built-up Beam post spacing is derived from the 2025 California Residential Code R507.5(1) 40 psf live-load reference using the modeled Joist Field tributary span.
- Intermediate effective joist spans are interpolated; spans beyond the table are never extrapolated.
- Existing solid 4×6, 4×8, 4×10, and 4×12 Beam options use their corresponding double-2× row only for preliminary support layout and display `Engineering review`.
- A Beam receiving joists from both sides uses the combined tributary span conservatively and remains marked for engineering review.
- Changing a Beam profile immediately regenerates the minimum post layout, plan graphics, and Framing Takeoff.
- Built-up Beam Takeoff counts each individual ply in commercial stock lengths; solid and custom Beam material remains marked `REVIEW`.
- Reference assumptions are No. 2 wet-service lumber, 40 psf live plus 10 psf dead load, zero beam cantilever, and the Douglas Fir-Larch / Hem-Fir / Spruce-Pine-Fir group. Local amendments and nonstandard loads require verification.
