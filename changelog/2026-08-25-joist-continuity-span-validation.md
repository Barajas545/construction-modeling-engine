# Joist continuity and CRC span reference

- Joist Fields now establish one continuous construction object per physical joist line instead of one object per supported bay.
- Ledger, beam, and rim intersections remain structured bays for span validation.
- Added the 2025 CRC / 2024 IRC R507.6 preliminary reference for Douglas Fir-Larch and Redwood groups at 12, 16, and 24 inches O.C.
- Added selectable warning markers for over-20-foot continuous runs and invalid or unrecognized span conditions.
- Warning acknowledgment is stored without suppressing the underlying validation result.
- Joist Takeoff now combines compatible short cuts into commercial 8, 10, 12, 16, and 20-foot boards.
- Added an independent Joists visibility sublayer.
