# Canvas layer toolbar simplified

Implemented on 2026-08-18.

- Preserved Undo and Redo in the floating canvas toolbar.
- Removed Edit corners, Draw outline, and Deck area from this toolbar; these remain available from the dedicated modeling tools where appropriate.
- Preserved the Dimensions visibility toggle.
- Added a quick Railing visibility toggle distinct from the Railing drawing tool.
- Added a serializable CAT construction lines visibility layer for the future CAT construction tool.
- Added CAT construction lines to the full Visibility panel.
- Made the compact toolbar horizontally resilient on narrow field devices.
