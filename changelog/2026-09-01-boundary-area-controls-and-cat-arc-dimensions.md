# Boundary Area Controls and CAT Arc Dimensions

- CAT Boundary area labels now behave like Deck Boundary area dimensions.
- CAT area labels have a leader arrow connected to the derived area and support independent label and arrow repositioning.
- Deck and CAT area properties provide **Hide this boundary** and **Show all boundaries**.
- Hiding preserves the area annotation so the user can restore the geometry without relying on another visible Boundary.
- Hidden state is serializable with the project and does not delete or modify construction geometry.
- Selected CAT arcs now display radius (R), chord-midpoint height (H), and midpoint nodes using CAT colors.
