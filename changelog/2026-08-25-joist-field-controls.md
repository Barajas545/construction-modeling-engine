# Joist Field profile, spacing, and deletion controls

- Removed individual profile editing from selected joists.
- Added field-wide 2×6, 2×8, 2×10, and 2×12 PT profile controls.
- Added 12″, 16″, 24″, and custom 1″–48″ O.C. field spacing.
- Regenerate the complete Joist Field, Blocking, validation, Ledger inheritance, and Takeoff after profile or spacing changes.
- Preserve valid manually added parallel joists during field regeneration.
- Added separate Delete selected joist and Delete entire Joist Field actions.
- Joist Field profile changes now synchronize Rim / Flush edges in the same Deck Boundary while preserving single or double ply configuration.
- Hiding the Joists layer now returns Rim / Flush edges to their ordinary Deck Boundary appearance and keeps them selectable.
- Complete-field deletion also removes its Blocking settings and remains recoverable through Undo.
