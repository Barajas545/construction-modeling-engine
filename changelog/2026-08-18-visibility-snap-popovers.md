# Visibility and Snap moved to tool popovers

- Added Visibility and Snap buttons directly above Details in the left tool rail.
- Moved Drawing Layers and Precision controls out of the permanent right inspector.
- Each button opens one mutually exclusive floating panel in the lower-left workspace.
- Added a highlighted connector between the active tool button and its floating panel.
- Added close-button, second-press toggle, Escape dismissal, and automatic dismissal when choosing a modeling tool or Details.
- Preserved all existing layer visibility, snap preferences, grid increment, and Fit Project behavior.
